# Китай 2026

Основа сайта на базе исходников «Европа 2026» от 16.09.2026.
Целевой адрес: https://china2026.proskurnin.com, сервер: 80.87.199.223.

Сайт не опубликован: доступ к SSH, DNS и HTTPS из текущей среды заблокирован.
Репозиторий: https://github.com/proskurnin/china2026.proskurnin.com. Исходники Европы не менялись.

## Запуск

Node.js >= 22.13; npm ci; npm run dev.
Проверка: npx tsc --noEmit. Статическая сборка: npm run build.
Публичный результат: dist/client. Не публиковать исходники, node_modules и личные резервные копии.

## Маршрут

Даты, города, бронирования и участники не предоставлены. data/plan.json содержит
пустой маршрут совместимого формата. В интерфейсе явно указано, что планируется поездка.
После заполнения или импорта плана доступны исходные карта, расписание, бюджет,
чек-листы, избранное, заметки и резервные копии. Валюта личных цен: CNY.
Заметки хранятся только в браузере; для переноса используется экспорт.
Google Maps ключ Европы не переносился; используется OpenStreetMap.

## Публикация через Git

1. Создать отдельный репозиторий Китая и отправить туда эти исходники.
2. Клонировать его на сервер в отдельный каталог, например /opt/china2026.
3. Из чистого checkout выполнить bash deploy/release-from-git.sh.
4. Установить deploy/china2026.proskurnin.com.conf в /etc/apache2/sites-available/.
5. Проверить фактическую конфигурацию сервера, включить новый virtual host,
   выполнить apachectl configtest и reload Apache.
6. После подтверждения DNS и доступности HTTP выпустить сертификат Let's Encrypt
   для china2026.proskurnin.com с webroot /var/www/letsencrypt и включить HTTPS.
7. Проверить HTTPS, вкладки, импорт плана и загрузку ресурсов.

Новый каталог и virtual host независимы от Европы. Откат — вернуть current
на предыдущий каталог выпуска. Скрипт автоматически останавливается при ошибке сборки.
